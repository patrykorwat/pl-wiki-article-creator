# Red flags — ryzyka przy tworzeniu artykułów

## Ryzyko usunięcia
- Brak niezależnych źródeł (poleganie tylko na stronie podmiotu).
- Temat lokalny bez znaczenia ogólnopolskiego.
- Artykuł promocyjny / marketingowy.
- Brak encyklopedyczności (notability).

## Ryzyko stubu
- Tylko 1-2 źródła.
- Brak infoboxu.
- Tylko jedna sekcja treści.

## Ryzyko POV / COI
- Język wartościujący („wybitny", „najlepszy", „pionierski").
- Brak wątków krytycznych.
- Źródła tylko od podmiotu lub sympatyków.

## Ryzyko techniczne
- Nieistniejące szablony infoboxów.
- Błędy w składni wikitekstu.
- Puste przypisy.
- Linki do nieistniejących artykułów (czerwone linki bez {{link-interwiki}}).

## Etyka
- Cytowanie książek bez dostępu = fałszowanie badań.
- Kopiowanie treści = naruszenie praw autorskich.
- Brak przypisów = artykuł do usunięcia.
